## Coding Rules to follow while coding

--> Always think step by step and write it down in the terminal using echo command to create a step tracking file.
--> Write diown all dependencies that will be installed in requirements.txt.
--> Don't start coding unless you have a complete plan.
--> Do not over engineer the project, keep it simple and efficient, and modern.

## Repository Structure rules

--> Do not dump everything inside a single file divide or simplify and organise it properly in folder structure and files.
  - For example : If there are schema rules like pydantic keep it in different files not inside the logic, keep prompt_versions different not inside the code, keep configs different not inside the code, keep helpers different not inside the code, crud operations in different file not inside api logic, Use routers and keep api strucgture clean and modular.
--> Always create a README.md file for the project explaining what it does and how to run it.
